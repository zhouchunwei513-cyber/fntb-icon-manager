客户端 API 与集成配置

以下 API 供飞牛 PC 客户端或其他应用调用，获取所有应用图标数据。

📡 PC 客户端集成方式

1. 在 PC 客户端设置页面添加 HTTP API 地址:
2. 客户端通过 GET /api/client/apps 获取应用列表（含自定义图标）
3. 客户端通过 GET /api/icons/{appname}/{size} 获取图标图片
4. 返回数据包含 title, icon, protocol, port, path, url 等字段，与 fnOS appcenter 格式兼容

⚡ 快捷方式启动优化建议

问题: 通过快捷方式打开第三方应用需等待约 15-20 秒。
原因: PC 客户端对非 appview 类型应用会触发 preauth 预认证流程，等待 20s 超时后才加载页面。
解决: fnOS 内置应用（trim.*）使用 appview 类型，无此延迟（约 3-7s）。建议为内置应用创建快捷方式。
